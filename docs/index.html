Architecture & Capabilities

Built for real mobile engineering workflows

Every layer is engineered for reliability on physical ARM64 Android hardware—offline or connected.

Resilient Multi-Provider SSE

Stream from Gemini, Claude, and OpenAI with chunked tool calls, reasoning blocks, 180s partial-preserving guards, and automatic 429/5xx retry.

On-Device Local LLM Hub

Download and verify GGUF models with SHA-256 checks, RAM load guards, real hardware profiling, and zero-API-key local inference via llama.cpp.

Linux Shell, Termux & Jobs

Run commands through Android toybox or Termux with persistent working directories, background job controls, and a local loopback WebView preview.

Approval Gate & Redaction

Every shell action passes risk classification and explicit user approval, while automatic secret redaction protects logs, transcripts, and crash reports.

Local-First Persistence

Conversations persist locally in JSON first so work is never lost offline, backed by 60-second throttled Firestore sync and a manual sync control.

Light-First Material 3 UI

Minimal Light/White Mode default with Dark/System themes, collapsible Thought Process blocks, grouped tool steps, and bottom-pinned composer.

Installation

Up and running in three steps

Requires an ARM64 (arm64-v8a) Android device running Android 7.0 (API 24) or newer.

  1. 01

    Download the APK

    Tap Download ZELKAI APK at the top of this page to fetch the latest CI-verified release build directly from GitHub Releases.

  2. 02

    Install on Android

    Open the downloaded .apk file. If prompted by Android, enable Install unknown apps for your browser or file manager.

  3. 03

    Pick Local or Cloud AI

    Launch ZELKAI, open the Local LLM Hub for offline GGUF models, or add your personal Gemini, Claude, or OpenAI API key in Settings.
